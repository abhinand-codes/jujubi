# jujubi

A sweet, animated single-page "ask her out" website made for Jeevitha (JJB). It is plain HTML, CSS, and JavaScript: no framework, build step, or dependency is required.

## Personalize it

- Change **JJB** in `index.html` (search for `EDIT: change JJB`).
- Replace the three paragraphs directly below `<!-- EDIT: personal message about Jeevitha goes here -->` in `index.html`.
- Set `YOUR_EMAIL` at the top of `script.js`. The confirmation button opens an email addressed there with the selected date and optional note.

## Preview locally

Open `index.html` in a browser. No local server is needed.

## Publish with GitHub Pages

1. Push these files to the `main` branch of [abhinand-codes/jujubi](https://github.com/abhinand-codes/jujubi).
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and the `/ (root)` folder.
4. Save. GitHub will display the public URL after deployment.

The reply address is already set in `script.js`; update it there if you ever want to use a different one.
